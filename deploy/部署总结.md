## 📝 部署流程概览

### 方式一：快速部署（推荐）

```bash
# 1. 上传项目到服务器
scp -r myblog root@49.235.139.118:/app/

# 2. SSH登录服务器
ssh root@49.235.139.118

# 3. 一键部署
cd /app/myblog/deploy
sudo ./quick-deploy.sh
```

### 方式二：分步部署

```bash
# 1. 初始化服务器
sudo ./server-setup.sh

# 2. 创建环境变量
./create-env.sh

# 3. 初始化数据库
./init-database.sh

# 4. 部署应用
./deploy.sh

# 5. 配置Nginx
sudo cp ../nginx/myblog.conf /etc/nginx/conf.d/
sudo nginx -t && sudo systemctl reload nginx
```

## ⚠️ 重要提示

### 安全配置（必做）
1. ✅ 首次登录后立即修改 admin 密码
2. ✅ 配置云服务器安全组：
   - 开放 80 (HTTP)
   - 关闭或限制 8081, 3000, 13306, 26739, 9200
3. ✅ 设置强密码（MySQL、Redis）
4. ✅ 定期备份数据

### 性能优化（建议）
1. 根据服务器内存调整JVM参数
2. 配置MySQL慢查询日志
3. 启用Redis持久化
4. 定期清理日志文件

### 后续改进
1. 配置域名
2. 启用HTTPS（需要域名）
3. 配置CDN加速
4. 设置监控告警

# 仓库清理指南

## 1. 清理目标

- 清理临时文件、构建产物、日志
- 保持仓库可读、可维护
- 避免误提交无关文件

## 2. 常见可清理对象

- 本地日志文件
- 临时下载文件
- 编辑器缓存
- 无效截图与调试产物

## 3. 建议命令

```bash
# 查看工作区变更
git status

# 预览未跟踪文件
find . -type f \( -name "*.log" -o -name "*.tmp" -o -name ".DS_Store" \)
```

## 4. 注意事项

- 不要删除正在使用的环境配置文件
- 不要把清理脚本写成破坏性操作（例如强制重置）
- 清理后执行一次构建验证

## 5. 发布前最小检查

- `git status` 无意外文件
- 无敏感信息变更
- 构建命令可通过

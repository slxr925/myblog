# 安全与敏感信息管理指南

## 1. 范围

本规范覆盖：

- 代码仓库中的敏感信息控制
- 配置与凭据管理
- 发布前安全检查

## 2. 禁止项

- 禁止提交真实密码、API Key、Token、私钥
- 禁止在 README / doc 中写真实主机与账号
- 禁止把生产配置文件纳入版本管理

## 3. 推荐做法

- 使用环境变量注入敏感值
- 使用最小权限账户
- 定期轮换凭据
- 日志中对敏感字段脱敏

## 4. 提交前检查

```bash
# 示例：在提交前搜索可疑字段
rg -n "password|secret|token|api[_-]?key|private[_-]?key" .
```

> 命中后需人工甄别，确认无真实敏感值。

## 5. 泄露处置流程

1. 立即失效相关凭据
2. 替换为新凭据
3. 清理仓库与发布记录中的泄露内容
4. 复盘原因并补齐防护

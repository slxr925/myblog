# 性能优化指南

## 1. 优化目标

- 降低核心接口响应时延
- 提升高并发时的稳定性
- 控制数据库与搜索集群压力

## 2. 常见优化策略

### 2.1 缓存优化

- 热点数据优先缓存
- 设计合理 TTL 与失效策略
- 避免缓存穿透与击穿

### 2.2 查询优化

- 关键查询建立索引
- 限制返回字段与分页大小
- 复杂查询拆分并异步化

### 2.3 异步化

- 非核心流程（通知、统计）走消息队列
- 主流程只保留必要写操作

### 2.4 前端体验优化

- 懒加载路由与组件
- 控制长列表渲染成本
- 减少无意义重渲染

## 3. 指标建议

- P50/P95/P99 延迟
- 错误率与超时率
- 缓存命中率
- 搜索查询耗时

## 4. 压测与回归

- 预发环境压测关键接口
- 发布后做基线对比
- 将性能回归纳入发布检查项

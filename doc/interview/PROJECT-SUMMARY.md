# 项目总结（面试版）

## 1. 项目定位

MyBlog 是一个前后端分离的内容社区型系统，目标是提供：

- 稳定的内容发布与互动能力
- 可扩展的搜索与通知链路
- 可落地的部署与运维流程

## 2. 核心能力

- 内容：文章发布、编辑、分类与标签
- 互动：评论、点赞、收藏、关注
- 搜索：关键词检索 + 建议
- 通知：事件驱动消息投递
- AI：摘要与关键词提取

## 3. 技术选型动机

- Spring Boot：后端主干框架，生态成熟
- React + TypeScript：前端工程化与可维护性
- Redis：缓存和热点读写优化
- Elasticsearch：全文检索与相关性排序
- Kafka：解耦异步事件流

## 4. 工程亮点

- 明确的分层结构与职责边界
- 统一脚本化部署（本地/生产）
- 配套迁移、健康检查、日志排查流程
- 文档化实践（部署、安全、面试说明）

## 5. 关键问题与改进

- 搜索日志噪声治理：区分建议请求与结果请求
- 详情页可用性：增强导航与推荐能力
- AI 响应处理：应用层过滤非预期输出

## 6. 可继续演进方向

- 完整 E2E 自动化回归
- 更多性能基线指标与告警规则
- 推荐策略进一步数据化迭代

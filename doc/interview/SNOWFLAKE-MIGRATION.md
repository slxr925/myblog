# 雪花 ID 迁移策略

## 1. 迁移动机

当系统进入分布式部署阶段，单库自增 ID 在扩展性与全局唯一性上会受限，需考虑雪花 ID。

## 2. 迁移原则

- 平滑迁移，不中断现网
- 支持回滚
- 兼容历史数据

## 3. 推荐路径

1. 新表优先使用雪花 ID
2. 老表通过双写/映射逐步过渡
3. 应用层统一 ID 类型（建议 Long）
4. 全链路校验后再切主

## 4. 风险点

- 时钟回拨导致 ID 异常
- 节点号冲突导致重复
- 上下游系统对 ID 类型假设不一致

## 5. 防护建议

- 节点号统一分配与登记
- 对时钟回拨做阻塞或降级处理
- 加入 ID 唯一性监控与告警

# 监控体系说明

## 1. 监控目标

- 及时发现故障
- 快速定位根因
- 为性能优化提供数据依据

## 2. 监控层次

### 2.1 基础设施层

- CPU、内存、磁盘、网络
- 容器存活与重启频率

### 2.2 应用层

- 接口响应时间
- 错误率/异常量
- 慢查询与超时请求

### 2.3 业务层

- 内容发布量
- 互动量（评论/点赞/收藏）
- 搜索请求与命中率

## 3. 告警策略

- 以“可行动”为目标，避免噪声告警
- 分级：提醒、警告、严重
- 告警需附带上下文信息（时间、接口、实例）

## 4. 排障流程

1. 先看整体可用性
2. 再看最近变更
3. 结合日志与指标定位
4. 临时止损后再做根因修复

## 5. 发布后观察

- 重点关注 30 分钟内错误率与延迟变化
- 对异常波动做记录，形成复盘条目

# 文档中心（doc）

本目录提供部署、架构、面试准备和工程工具文档。

## 目录说明

- `deploy/`：部署、迁移、SSH 与迭代发布流程
- `interview/`：项目总结、设计模式、性能、监控与迁移策略
- `tools/`：环境配置、安全规范、仓库清理

## 推荐阅读顺序

### 新同学入项

1. `../README.md`
2. `deploy/DEPLOYMENT.md`
3. `tools/ENV-CONFIG.md`
4. `tools/SECURITY.md`

### 日常开发

1. `deploy/QUICK-ITERATION.md`
2. `tools/CLEANUP.md`

### 面试准备

1. `interview/PROJECT-SUMMARY.md`
2. `interview/INTERVIEW-GUIDE.md`
3. `interview/PERFORMANCE-GUIDE.md`
4. `interview/MONITORING-SYSTEM.md`

## 维护原则

- 文档中的所有主机地址、账户、密钥、口令均使用占位符
- 只描述流程和规范，不存放真实敏感信息
- 脚本命令优先与仓库当前目录结构保持一致
